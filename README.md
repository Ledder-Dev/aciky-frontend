# ACIKY Frontend (yoga-v2)

Frontend bilingüe (ES/EN) del centro de Kundalini Yoga ACIKY (Cuba). Vanilla JS + Vite + Tailwind CSS 4, sin frameworks.

Ver `CLAUDE.md` para contexto completo (arquitectura, convenciones, estado actual, decisiones).

## Build & Run
```bash
npm install
npm run dev       # localhost:5173
npm run build
npm run preview
```

Backend separado en `../yoga-backend/`.
